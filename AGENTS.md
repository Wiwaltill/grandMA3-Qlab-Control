# Codex development instructions
Read SPECIFICATION.md and ROADMAP.md before implementing. Target grandMA3 2.5.1.1 and QLab 5 (QLab version assumption to confirm). Build a native Lua plugin with a persistent native MA layout, macros and appearances. V1 must not require a Mac helper or timecode. Verify actual MA Lua APIs, XML import/export format, command argument handling and OSC syntax against official version-specific documentation; prior chat examples are hypotheses, not tested commands. Never invent runtime test results. Separate pure command parsing/configuration from MA runtime adapters; mock the latter in automated tests. Validate cue identifiers as strings (including decimals), whitelist actions, safely quote commands and reject malformed inputs. Never overwrite unrelated pool objects; preflight all slots, track owned objects, support safe reinstall and cleanup. Do not transmit OSC during installation or setup without explicit test action. Do not hardcode real network addresses or credentials. Keep panic explicit and confirmed; do not use workspace-wide stop for ordinary song transitions. Label state as last requested, never confirmed playback in V1. Document known limitations and manual onPC/console + QLab tests. Preserve LICENSE. Use small reviewable commits, versioned releases and importable ZIP assets. User-facing docs should include German setup instructions; English code/UI labels are acceptable.
